# Voicemo

An accessibility-focused desktop application that analyzes speech
emotion during online meetings and represents detected emotions using emojis.

## Planned Features

- Turkish and English speech recognition
- Speech emotion recognition
- Whisper integration
- emotion2vec integration
- PyTorch-based inference
- Real-time emotion visualization
- Emoji-based emotional cues
- Local-first processing
- Accessibility-focused meeting experience

## Tech Stack

- Python
- PySide6
- PyTorch
- Whisper
- emotion2vec
- ONNX Runtime
- pytest
